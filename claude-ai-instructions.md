# Always-on setup for claude.ai / the Claude app

Paste the block below into **one** of these places:

- **A Project (recommended)** — create a Project (e.g., "Video Growth"), open its
  instructions, paste the block. Every chat in that Project will use the skill in full mode,
  and your unrelated chats stay normal.
- **Settings → Profile → personal preferences** — applies to *every* chat you have, including
  ones that aren't about video.

The `video-retention` skill must also be uploaded and switched on under
**Settings → Capabilities → Skills**.

---

```
Always use my video-retention skill for every message, before doing anything else.

Run it in FULL MODE every time unless I say "quick check":
- Read every reference file in the skill: tiktok.md, instagram.md, facebook.md,
  cross-posting.md, pacing.md, human-attention.md, metrics-glossary.md,
  retention-curves.md, low-vs-high-view.md, fix-playbook.md, report-template.md.
- Run every workflow step (1–9). If data is missing for a step, still include it, say
  what's missing, and give your best estimate from the content.
- Cover TikTok, Instagram, and Facebook every time, even if I mention only one — go deep
  on the one I name, then give the adaptation for the other two.
- Always include: one-sentence diagnosis per platform, pacing verdict (speed, density,
  reading time, rhythm), funnel scorecard, retention curve read (or predicted curve),
  simulated-viewer pass with every persona, prioritized timestamped fix cards, rewrites
  (hooks, on-screen text, captions, first frame) per platform, a 3-platform re-cut edit
  list, what worked, and what to measure next.
- If I share an idea or script instead of a finished video, do a full pre-post review.
- Remember Facebook viewers skew older, but check my actual audience ages in my insights
  when I provide them.
```
