# Report Template

Use this structure for full analyses. For "quick check" requests, output only sections 1–2.
Keep language plain; explain jargon the first time it appears.

---

## 1. Diagnosis (one sentence)
> "<Video> is losing people at <stage> because <human reason>; fixing <X> is the biggest lever."

Then one line on data confidence:
> "Based on <N> views (<regime>) — <what the data can / can't support>. Inputs used:
> <transcript / frames / graph screenshot / metrics>."

## 2. Top 3 fixes
Three fix cards (format in `fix-playbook.md`), highest priority first.

## 3. Funnel scorecard

| Stage | Metric(s) | Value | vs baseline | Status |
|---|---|---|---|---|
| Distribution | Impressions | … | … | ✅ / ⚠ / ❌ / ? (no data) |
| Packaging | CTR / viewed vs swiped | … | … | … |
| Hook | Retention at 0:30 / 0:03 | … | … | … |
| Body | Slope / APV | … | … | … |
| Payoff | End retention / completion | … | … | … |
| Satisfaction | Engagement, subs/1k views | … | … | … |

## 4. Retention curve read
- Shape: <shape name> — what it means here.
- Events table:

| Time | Change | On screen / said | Viewer feeling | Cause |
|---|---|---|---|---|
| 0:07 | −18 pts | "Before we start, subscribe…" | "Get to the point" | Preamble delays promise |

## 5. Simulated-viewer pass
Compact persona table (see `human-attention.md`), plus 2–3 sentences on where it agrees or
disagrees with the real data.

## 6. All fixes (full list)
Remaining fix cards, grouped:
- **This video (do now)**: title/thumbnail/trim/chapters/pinned comment/end screen.
- **Next video**: hook, structure, pacing, format, topic.

## 7. Rewrites
- 3–5 title options.
- Thumbnail concept(s) described precisely (subject, expression, text, colors, composition).
- 2–3 hook scripts (exact words + what's on screen).
- Any rewritten lines for problem moments.

## 8. What worked (keep doing)
Specific strengths with timestamps — spikes, strong moments, good choices. (Always include;
creators need to know what not to break.)

## 9. Measure next
- Which metrics should move and by roughly when.
- Experiments for the next 3–5 videos (one variable each).
- Data that would sharpen this analysis (e.g., timestamped transcript, traffic-source split,
  retention by new vs returning, the channel's last 10 videos' CTR/APV).

---

### Style rules
- Lead with conclusions; details after.
- Timestamps everywhere possible.
- Numbers you didn't receive are either omitted or labeled "estimate".
- No generic advice without a tie to this video.
- Be direct but kind — the creator made something; point to what to change, not blame.
