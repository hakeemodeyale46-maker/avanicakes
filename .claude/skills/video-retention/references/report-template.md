# Report Template

Use this structure for full analyses. For "quick check" requests, output only sections 1–3.
If the video is on several platforms, repeat sections 1–6 per platform (or use a column per
platform), then add section 7. Keep language plain; explain jargon the first time.

---

## 1. Diagnosis (one sentence per platform)
> "On <platform>, <video> is losing people at <stage> because <human reason>; fixing <X> is the
> biggest lever."

Then one line on data confidence:
> "Based on <N> views (<regime>) — <what the data can / can't support>. Inputs used:
> <video / transcript / frames / insight screenshots>. Audience: <age/location if known>."

## 2. Pacing verdict
| Section | Time | Speed | Density | For this platform's audience |
|---|---|---|---|---|
| Hook | 0:00–0:03 | TOO SLOW | TOO LITTLE | FB 55+ OK, TikTok too slow |
| Build | 0:03–0:12 | RIGHT | TOO MUCH | 3 text boxes + stickers + music over voice |
| Reveal | 0:12–0:14 | TOO FAST | RIGHT | Reveal held 1s — needs 3s+ |

Rhythm line: `fast → slow build → fast montage → held reveal → quick CTA` (actual vs ideal).
Text readability: which on-screen texts are too short-lived, too long, too small, or
badly placed.

## 3. Top 3 fixes
Three fix cards (format in `fix-playbook.md`), highest priority first.

## 4. Funnel scorecard
| Stage | Metric(s) | Value | vs account baseline | Status |
|---|---|---|---|---|
| Distribution | Reach, % non-followers | … | … | ✅ / ⚠ / ❌ / ? |
| Stop | Skip rate / 3-sec views ÷ reach / 0–3s drop | … | … | … |
| Hook | Retention at ~3s, ~10s | … | … | … |
| Body | Avg watch time ÷ length, slope | … | … | … |
| Payoff | Watched full % / end retention | … | … | … |
| Satisfaction | Shares, saves, comments, follows per 1k | … | … | … |

## 5. Retention curve read
- Shape: <shape> — what it means here.
- Events:

| Time | Change | On screen / said / text | Pacing at that moment | Viewer feeling | Cause |
|---|---|---|---|---|---|

## 6. Simulated-viewer pass
Persona table using the platform's personas, plus 2–3 sentences on agreement/disagreement
with the real data.

## 7. Cross-platform comparison (if on 2–3 platforms)
Side-by-side key ratios; what the differences reveal (usually pacing or audience fit); and the
edit list for each platform's version (format in `platforms/cross-posting.md`).

## 8. All fixes
Remaining fix cards grouped:
- **This post (do now)**: caption, cover, pinned comment, replies, sharing to Stories/groups.
- **Repost / re-edit**: new cuts per platform.
- **Next video**: hook, pacing, structure, format, topic.

## 9. Rewrites (per platform)
- 2–3 hook lines (spoken + on-screen text) for TikTok, Instagram, and Facebook.
- First-frame / cover concept (subject, framing, text, colors).
- Caption first lines.
- Rewritten on-screen text with timings.

## 10. What worked (keep doing)
Specific strengths with timestamps.

## 11. Measure next
- Which metrics should move on which platform.
- Experiments for the next 3–5 videos (one variable each).
- Data that would sharpen the analysis (retention graph per platform, audience age, traffic
  source, the account's last 10 videos' key ratios).

---

### Style rules
- Lead with conclusions; details after.
- Timestamps everywhere possible.
- Numbers you didn't receive are omitted or labelled "estimate".
- No generic advice without a tie to this video and platform.
- Be direct but kind.
