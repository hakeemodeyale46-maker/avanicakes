# Cross-Posting: One Video, Three Cuts

Posting the exact same file on TikTok, Instagram, and Facebook is the most common reason a
video works on one platform and fails on the others. Treat it as **one shoot, three edits**.

## Side-by-side

| | TikTok | Instagram Reels | Facebook |
|---|---|---|---|
| Default audience | Younger-skewing, swipe-trained | Broad, visual, social | Older-skewing, community/family |
| Sound | Usually on | Mixed — design for muted | Often muted in feed |
| Hook window | ~1s | ~1–2s | ~2–3s, instantly clear muted |
| Pacing speed | Fastest | Fast, smooth, on the beat | Steady, clear, key shots held |
| Density (layers) | 2–4 | 2–3, clean | 1–3, simple |
| On-screen text | Short, punchy, can change fast | Short, styled, consistent | Large, plain, held long, one line |
| Language | Casual, trend-aware | Casual, polished | Plain, warm, no slang |
| Ending | Loop or open question | Loop or beautiful final shot | Clear, complete, satisfying |
| Top action to design for | Shares, rewatches, comments | Sends, saves | Shares to family, comments, messages |
| Typical length | Shortest complete version | Short/loopable | Can run longer if story is clear |

## Re-cut procedure

Start from the raw footage or the longest edit, then make three versions:

**TikTok cut**
1. Cut the first 1–3s until the action starts.
2. Tighten every pause; jump-cut speech.
3. Hook text ≤ 6–8 words; spoken hook first line.
4. Use a native/trending sound where appropriate.
5. End on a loop or a comment-bait question (honest).

**Instagram cut**
1. Pick the most beautiful first frame; set a clean grid cover.
2. Re-time cuts to the music beat.
3. Remove clutter; one consistent text style.
4. Make sure it works muted.
5. End on the prettiest shot; CTA to send/save.
6. Export without the TikTok watermark.

**Facebook cut**
1. First frame: clear image + large plain text line describing the story.
2. Hold key shots ~2–5s; slow down text so it can be read (~0.5s per word + ~1.5s).
3. Burned-in captions for all speech; large and high contrast.
4. Replace slang/trend references with plain language; add context the TikTok version assumed.
5. Remove extra layers (stickers, heavy SFX, rapid zooms).
6. Give the reveal and the reaction room (3–5s).
7. Clear ending + plain CTA (share / message to order).
8. Export without other platforms' watermarks.

## Output format for a 3-platform re-cut request

For each platform give:
```
PLATFORM: <TikTok / Instagram / Facebook>
Target length: <s>
Edit list:
  0:00–0:02  <action: cut / keep / hold to Xs / replace text with "…">
  ...
On-screen text (with timings):
Caption (first line matters most):
Sound/music:
Cover/first frame:
CTA:
Pacing verdict before → after:
```

## Comparing results across platforms
- Compare average watch time ÷ length, completion, shares per 1,000 views, and non-follower
  reach per platform.
- A video that wins on TikTok and loses on Facebook usually needs a **slower, clearer,
  muted-friendly** Facebook cut — not a different topic.
- A video that wins on Facebook and loses on TikTok usually needs a **faster start and
  tighter pacing** for TikTok.
- A video that does well everywhere except Instagram often needs **cleaner visuals, a better
  cover, and a send/save trigger**.
